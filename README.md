# Page views explorer

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://your-app-url.streamlit.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Explore daily page views for a web platform across countries and devices. Built with Streamlit, pandas, SciPy and
Plotly.

## What it does

- Filter by date range, region, country and device
- Headline figures compared with the period of equal length just before
- Trend by day, week or month; a partial final week or month is left out so the line never ends on a false dip
- Breakdown tabs: map and top countries, device and region mix, weekday pattern and a year-by-month seasonality heatmap,
  engagement
- A list of unusual days found against a rolling median with a robust score, which does not flag the newest days of a
  rising trend

## Run it

```bash
pip install -r requirements.txt
streamlit run app.py
```

Needs Python 3.11 or newer. The theme follows your system's light or dark setting and is defined in
`.streamlit/config.toml`.

## Test it

```bash
pip install -e ".[dev]"
pytest
```

The tests cover the analysis code, the page itself (run headlessly with Streamlit's `AppTest`) and the dependency pins:
`tests/test_pillow_security_*.py` fails if Pillow is capped below 13 or Python 3.10 is allowed, because older Pillow
releases carry known security advisories.

## Notes

The data is synthetic. It is generated by `scripts/synthesize_data.py` for demonstration and describes no real site.

Part of [Data Flakes](https://www.data-flakes.dev/).
